# Storybook 蜡笔海洋融合优化：验证结果

日期：2026-11-07

## 本轮实现

- 保留原挂机钓鱼、倾斜、浮漂命中、专注、奖励、图鉴、Zen、天气和存档。
- 云改为 3 族 8 种轮廓，拥有进入、经过和离开的生命周期，不再原地循环。
- 云采用生成时并发限制，最多 4 个，避免累积与突然截断消失。
- 岛采用生成时并发限制，最多 2 个，避免多座灯塔连成一排。
- 海鸥、鱼群和跳鱼使用独立的 seeded 环境时间表，不使用奖励鱼 RNG。
- 海浪、浮力、钓竿、鱼线和浮漂保持原有运动关系。
- 限制 30fps，移动端 DPR 1.5，桌面 DPR 2，后台不补跳动画时间。
- 未加入贸易、港口经营、船只升级或新货币。

## 工程证据

- `npx tsc --noEmit`：通过。
- `npm run build`：通过。
- 倾斜回归：shipX 672.0 → 731.3（右倾），随后回到 645.5（左倾）。
- 浮漂命中：进入 REELING，命中距离 1.10px。
- FishDex：Nemo-ish 和 Dory-ish 正常显示。
- Zen：时间／风力两个滑块正常，Night 正常。
- 90 秒连续录制：无运行异常。
