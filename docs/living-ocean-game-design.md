# 海上航行：活着的儿童绘本海洋

版本：0.1（动态体验方向稿）
日期：2026-11-07

## 1. 一句话愿景

一款儿童蜡笔／油画棒绘本风的挂机航海游戏：小船持续在真实移动的航线上前进，云、岛、动物、港口和事件从身边经过；玩家每次回来，都能看见一段不一样的海上小故事。

不是“会动的壁纸”，而是“会自己生活的绘本”。

## 2. 当前问题与目标

| 当前页面 | 目标体验 |
|---|---|
| 天空长期只有一张纹理 | 天空保持纸感，但随航线、时间和天气缓慢变化 |
| 云形相似、位置固定感强 | 多族云形、不同速度、持续进入和退出 |
| 岛屿固定在背景 | 远、中、近岛按不同速度经过，成为航线地标 |
| 海面只有重复浪纹 | 海浪有深浅、局部泡沫、船尾流和事件性水花 |
| 没有海上生物 | 海鸥、鱼群、跳跃鱼、海豚等组成环境事件 |
| 永久停留在同一构图 | 连续航行、经过航段、靠近并抵达港口 |
| 小船是唯一活物 | 世界即使玩家不操作也在生活 |

## 3. 四条体验原则

1. **纸画感优先**：所有物件保留蜡笔笔触、纸张咬合和稚拙轮廓，不做写实 3D、PBR 或光滑矢量渐变。
2. **世界先于装饰**：云、岛和动物是航线中的位置与事件，不是随机飘来的贴图。
3. **安静但不空白**：不做满屏粒子；每次只让少数事物吸引注意，保留海面留白。
4. **孩子能读懂**：所有运动都有明确来源和方向，能一眼看出“船在向前、风在吹、岛在靠近”。

## 4. 世界如何真正航行

采用连续侧视航线。小船位于画面中左部，镜头跟随航程，世界从右向左经过。

航线由不同航段组成：

```text
母港出发 → 近岸岛屿 → 开阔海面 → 鱼群水域 → 灯塔水道 → 目的港
```

每个航段拥有自己的背景组合、云族、岛屿、海色、动物和事件池。玩家不能在每一趟都看到完全相同的页面。

### 视差层级

- 远云、远岛：移动最慢，提供方向和距离；
- 中景云、岛、灯塔：速度适中，是主要地标；
- 海面中层：持续流动；
- 小船与近景生物：保持主要可读性；
- 前景浪花、漂浮物：速度最快，增强经过感。

## 5. 各类素材与运动规范

### 天空

天空纹理不能每帧闪动。纸张和蜡笔底纹保持稳定，缓慢变化的是：

- 航线区域的海天色温；
- 日出、正午、黄昏和夜晚的预制色彩状态；
- 云层覆盖时的局部明暗；
- 天气锋面经过时的整体氛围。

太阳圆盘保持稳定，光芒可以慢转。不能把整张天空图来回拖动伪装成航行。

### 云

首批至少准备 **3 族、每族 4 种轮廓，共 12 种云**：

- 扁长云：低、慢、横向延展；
- 圆团云：饱满、轮廓不规则；
- 碎云／远云：小、淡、移动更慢。

规则：

- 同一视口内不得出现明显复制粘贴的云；
- 每朵云有独立速度、尺寸、透明度和前后层；
- 云从画面外生成并自然离开，不在固定位置循环；
- 避免 5～10 秒内重复同一轮廓、同一大小、同一位置；
- 可镜像和缩放复用，但不能只靠一种云翻过来倒过去。

### 岛屿

首批至少 6 类：圆岛、长岛、双岛、岩石岛、灯塔岛、港口岛。

- 远岛移动慢，中近岛移动快；
- 岛从右侧进入、左侧离开；
- 到港岛从远处逐渐变大，并出现码头、建筑和船坞；
- 岛可以附带海鸥、灯、旗、烟或居民活动；
- 同一航段避免连续出现相同轮廓。

### 海面

- 保留三层统一风格的动态浪纹；
- 船尾有独立航迹和扩散泡沫；
- 近景水花速度与船速、风浪有关；
- 鱼群水花、雨滴和到港浪花属于事件层，不与普通浪纹混用；
- 海底纸张纹理静止，所有可读浪形统一运动。

### 海鸥

不是永远循环飞过屏幕，而是有行为：

- 远处一小群掠过；
- 单只从船前穿过；
- 绕船一周后飞走；
- 在岛屿或灯塔上停留，船靠近时飞起。

海鸥翅膀使用少量手绘帧，身体沿轻微弧线移动。

### 鱼群与海洋生物

- 水面下出现同一方向的鱼群剪影；
- 鱼群改变一次方向后离开；
- 偶尔 2～3 条鱼依次跃出，带手绘水花；
- 海豚是低频惊喜，不每次航程都出现；
- 特殊鱼种可与航线、天气和钓具等级关联。

### 其他事件

漂浮瓶、木箱、浮标、远方帆船、彩虹、灯塔扫光、近岸小船和港口迎接。

## 6. 航线导演系统

不能简单按随机数每帧生成事件。使用可复现的 seeded RNG 与事件预算。

### 推荐节奏

- 每 15～25 秒一个轻环境事件：海鸥、远鱼、小岛、云形变化；
- 每 45～90 秒一个可记忆事件：鱼群跃出、海豚、漂浮瓶、灯塔；
- 同一时刻最多一个主事件，避免所有东西一起出现；
- 重要事件发生时，降低其他动画的注意力，不让玩家错过。

### 示例：90 秒航程

| 时间 | 内容 |
|---|---|
| 0–10 秒 | 母港离开，船加速，近岸物体后退 |
| 10–25 秒 | 两种云族经过，第一座远岛出现 |
| 25–40 秒 | 海鸥从船前掠过，鱼群在水下经过 |
| 40–55 秒 | 双岛水道，船从中穿过，岛逐渐后退 |
| 55–70 秒 | 三条鱼依次跃出，偶尔出现漂浮瓶 |
| 70–85 秒 | 灯塔和目的港进入，建筑逐渐变大 |
| 85–90 秒 | 船减速靠岸，出现航程收据 |

## 7. 儿童蜡笔画应该是什么感觉

### 形状

- 大色块、略歪的比例、孩子能画出的简单几何；
- 船、岛和动物先保证剪影，再补少量细节；
- 不追求真实透视和精确比例，但运动关系必须合理。

### 笔触

- 色块内部有叠色、断笔、纸张露出；
- 不依靠全屏噪点冒充蜡笔；
- 纹理跟随物件，不随镜头随机闪烁。

### 动画

- 镜头和船体保持平滑；
- 翅膀、旗面、水花可使用少量手绘帧制造手作感；
- 不用“全画面低帧率”冒充绘本动画，避免被感知为卡顿。

## 8. 与玩法系统的连接

- 船舱容量影响可见货物和航程收益；
- 引擎影响船速、浪纹与经过岛屿的速度；
- 钓具影响鱼群种类和钓鱼事件；
- 港口订单决定航线和可能经过的地标；
- 港口升级会逐渐增加灯、旗、建筑、居民和迎接小船。

鱼和贸易品共用货舱。航行时间同时是贸易成本和挂机钓鱼时间。

## 9. UI 原则

- 常驻 UI 只保留目的地、航程进度和少量资源；
- 事件在场景附近用简短绘本气泡表达；
- 到港后才出现完整收据：鱼、货物、订单、金币和解锁；
- 不用大卡片长期遮住天空、动物和港口；
- 不增加圆形转场。

## 10. AI 生图与 Canvas 的正确分工

### AI 负责

- 云族、岛族、鱼类、海鸥、船部件和港口状态的可复用素材；
- 少量动作帧与色彩版本；
- 概念视频，用于确认运动方向与整体氛围。

### Canvas 负责

- 镜头、视差、对象生命周期、航线和 seeded 事件；
- 翅膀、旗面、水花和船的确定运动；
- 缓存、透明合成、交互和性能。

禁止每帧调用生图 API。API key 不进入前端。

## 11. 下一个动态 Demo 范围

只验证一条 **90 秒晴天航线**：

- 3 个航段；
- 至少 6 种可见云形；
- 3 座不同岛屿进入和离开；
- 1 次海鸥事件；
- 1 次鱼群事件；
- 1 次跳跃鱼或海豚事件；
- 1 个可收集漂浮瓶；
- 1 次真实到港过程。

暂不做完整贸易、天气循环、复杂 NPC 和全 3D。

## 12. 验收标准

- 90 秒内不会一直停留在同一构图；
- 同屏云不再明显复制；
- 岛能进入、靠近、后退；
- 海浪、船尾流和事件水花来源合理；
- 至少有 3 种不同的海上生物或事件出现；
- 玩家能明确说出“我刚经过了一座岛，接下来要到港”；
- 目标设备运行稳定，事件不引起明显卡顿。

## 14. Seedance 2.5 概念片复核

概念片：[海上航行](../public/sunny-sailing-demo/concept-ocean-voyage.mp4)

实际输出：Seedance 2.5 Image-to-Video Turbo，5.04 秒，1280×720，24 fps。

### 已验证的方向

- 连续侧视航行比固定构图更有旅程感；
- 海鸥和海豚跃出能形成明确的海上事件；
- 岛屿后退能帮助理解船在前进；
- 灯塔和码头出现，让一段航程拥有目的地；
- 蜡笔纸纹在概念片里基本保持一致。

### 不应直接照搬的部分

- 云形仍然不够丰富，正式游戏需要云族资产库和生成规则；
- AI 视频里的动物出现时机不可控，正式游戏必须由航线导演决定；
- 概念片没有证明水下鱼群、长期重复可玩性或手机性能；
- 不用概念片替代真实可玩的 90 秒航线验收。

### 对后续实现的直接影响

1. 优先实现真实航线、岛屿生命周期和到港，而不是继续修饰固定海面。
2. 动物按事件出现，不能每趟、每分钟都成群重复。
3. 云族至少达到 3 族 12 种后再扩展更多生物。
4. 到港必须是场景中的真实过程，不是直接弹结算卡。


## 15. 原始玩法保持约束（本轮换画风）

本轮只升级视觉与环境表现，不把游戏改成贸易或港口经营游戏。

### 不可变能力

- 倾斜设备控制小船左右移动，保留死区、加减速和边界反弹；
- 保留抛竿、等待、收竿及点击浮漂的命中逻辑；
- 保留 15／30／45 分钟专注计时和 Wake Lock；
- 保留奖励鱼、稀有度、鱼类故事生成及失败回退；
- 保留 FishDex、鱼类去重与 localStorage 存档；
- 保留 Zen 模式、时间／风力／天气控制；
- 保留定位与真实天气同步；
- 保留 Rainbow、雨、雪、闪电等原有环境状态。

### 只做增强

- 绘本分层素材、统一海浪、云族和岛屿视差；
- 不改变规则的海鸥、鱼群和环境事件；
- 更好的帧率独立动画、DPR 与素材缓存。

### 本轮不加入

- 船只贸易、港口经营、NPC 订单、船只属性升级；
- 新货币、新核心玩法或替代原专注计时的航线系统；
- 全 3D 场景、自由镜头和页面圆形转场。
